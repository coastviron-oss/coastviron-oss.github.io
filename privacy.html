Privacy Policy

CK Chat Memory · Effective 2026-10-08

Data accessed

With the operator's consent, CK Chat Memory reads, through the Google Chat API with read-only scopes (chat.spaces.readonly, chat.messages.readonly): the list of Google Chat spaces the operator belongs to, and the messages, message metadata (time, sender resource name, edits, deletions) and attachment metadata in those spaces.

How it is used

The data is used only to give the operator a private, searchable archive of their own conversations. Search results may be passed to an AI model to answer the operator's own questions; Google user data is not used to develop, improve, or train generalized AI or machine-learning models.

Storage and sharing

Data is stored in a private database and private file storage controlled by the operator, with access restricted to the operator. It is not sold, not shared with third parties, not used for advertising, and not published. Data is transferred only to the infrastructure providers that host the operator's database, to the extent needed to run the tool.

CK Chat Memory's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

Data is kept as long as the operator uses the tool. Access can be revoked at any time at myaccount.google.com/permissions; the operator can delete the stored archive at any time.

개인정보처리방침 (요약)

  • 읽는 정보: 운영자가 속한 Google Chat Space 목록, 메시지와 그 메타데이터(시각, 수정·삭제 기록), 첨부파일 정보. 읽기 전용 권한만 사용합니다.
  • 사용 목적: 운영자 본인의 대화를 비공개로 보관·검색하는 것뿐입니다. 검색 결과 일부를 운영자 질문에 답하기 위해 AI 모델에 전달할 수 있으나, 범용 AI 모델 학습에는 쓰지 않습니다.
  • 보관: 운영자만 접근할 수 있는 비공개 데이터베이스에 저장합니다. 판매·제3자 제공·광고·공개하지 않습니다.
  • 철회: myaccount.google.com/permissions에서 언제든 권한을 해제할 수 있고, 운영자는 저장 자료를 언제든 삭제할 수 있습니다.
