CK Chat Memory

Private, single-operator tool / 운영자 1인 전용 내부 도구

What it does

CK Chat Memory keeps a private, searchable archive of the operator's own Google Chat conversations. It signs in with the operator's Google account and requests read-only access (chat.spaces.readonly, chat.messages.readonly) so it can list the spaces the operator belongs to and copy their messages into the operator's private database for search. It never sends, edits, or deletes Google Chat messages.

The tool is not offered to the public. Only the operator signs in to it.

하는 일

CK Chat Memory는 운영자 본인의 Google Chat 대화를 비공개로 보관하고 검색하는 도구입니다. 운영자의 Google 계정으로 로그인해 읽기 전용 권한만 받아, 운영자가 속한 Space와 메시지를 운영자 전용 비공개 데이터베이스에 복사해 검색할 수 있게 합니다. Google Chat 메시지를 보내거나 고치거나 지우지 않습니다. 일반 사용자에게 제공하지 않으며 운영자만 로그인합니다.
